# 业务分析任务工作台三轮使用测试

日期：2026-08-23

## 测试环境

- Chromium（Playwright 1.62.1）
- Codex CLI 0.148.0-alpha.9
- 腾讯 WorkBuddy/CodeBuddy 2.115.0
- 示例场景：增长质量预警，12 条指标记录、2 个指标、6 个日期、1 份文本材料

## 第一轮：无模型完整业务路径

从空工作台创建“增长质量复盘”任务，经本地路径预览并锁定数据快照，导入文本，运行确定性分析，回放 9 个持久化事件，查看证据图并下载报告。

真实浏览器首次运行发现 API 客户端把原生 `fetch` 作为未绑定函数传递，Chrome 抛出 `Illegal invocation`。已增加浏览器回归并改为通过 `globalThis.fetch` 包装调用。修复后，12 条记录、KPI、趋势、分布、文本主题、运行事件和证据关系均可见。

## 第二轮：真实本地助手

在只读模式连接腾讯 WorkBuddy/CodeBuddy 2.115.0，发送只允许使用 `WORKBENCH TASK CONTEXT` 的请求。助手准确返回当前任务名和 0 个锁定资产，未收到原始数据、文件路径或未选文档内容；没有触发审批，没有浏览器控制台错误，完整连接与回答耗时 8.3 秒。

Codex CLI 0.148.0-alpha.9 已通过适配器、权限、流式、错误恢复和服务端边界测试；本轮真实提供方选择了先前确定的腾讯 WorkBuddy。

## 第三轮：失败恢复、窄屏与交付报告

同一次导入包含 1 份有效文档和 1 个不存在的路径。测试发现前端刷新任务快照后会重新生成文本 Dashboard，从而把“1 个失败”覆盖为 0。修复后，导入诊断作为任务级制品绑定当前文档快照集合，刷新与报告导出仍显示 1 份文档、1 个失败；文档集合变化时自动失效重算。旧 SQLite v1 工作区可原地迁移到 v2。

下载的报告被真实浏览器以本地 `file:` 页面重新打开，Executive Summary 和内联 SVG 正常显示，外部 HTTP(S) 请求为 0。390×844 视口无横向溢出；`prefers-reduced-motion` 下不依赖动画才能访问结果。
